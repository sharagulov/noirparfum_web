# Изображения

- `brand/hero.png`, `hero.webp` — OG и брендинг.
- `editorial/about.png`, `about.webp` — блок о бренде.

- `products/flacons/{slug}.png` — флаконы для карточек каталога (имя = `slug` из `products.json`).
