# NOIR Parfum Full

Полноценный frontend-сайт бренда нишевой парфюмерии на основе эталонного лендинга `noirparfum`.

## Запуск

```bash
npm install
npm run dev
```

## Структура

- `src/data` — редактируемые JSON-данные бренда, товаров, коллекций и сервисных сценариев.
- `src/components` — переиспользуемые UI-компоненты.
- `src/pages` — страницы сайта.
- `src/state` — корзина, сравнение и локальное состояние.
- `public/images` — изображения, которые можно заменить своими файлами без изменения логики.

## Проверка

```bash
npm run check:data
npm run build
npm run test
```
